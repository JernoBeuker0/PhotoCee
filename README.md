# Converting Raw camera files to JPG

Before trying to run, make sure that you have you venv activated.

To actually run this script, make sure to have the photos in the 'input' folder. The photos are also expected to be in a folder, which name you have to put in the line when running the python script as follows:

```python
python change_sig.py NAME_OF_FOLDER
```

After running, the original files are still there and the new ones are in the output folder.
